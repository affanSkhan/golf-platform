# Digital Heroes Golf Platform

A full-stack golf performance, charity contribution, and monthly draw platform based on the Digital Heroes 2026 PRD.

## Planned stack
- Next.js + TypeScript
- Tailwind CSS
- Supabase Auth/Postgres/Storage
- Stripe subscription abstraction
- Role-based user/admin dashboards
- Deterministic draw engine with simulation and audit records
- Responsive, motion-enhanced UI

## Status
Implementation in progress.
